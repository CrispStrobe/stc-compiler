Transpiling is local; compiling is not. Turning C into a flashable image needs SDCC or avr-gcc, which are native binaries this page cannot run, so Compile to .hex posts the generated source to the hosted API at stc-compiler.vercel.app and everything else stays here. A micro:bit needs no compiler at all — MicroPython is interpreted on the device — and an Arduino sketch is built by the Arduino IDE, so for those the download is the deliverable.

RISC-V is the exception. Tick RISC-V C, write C, and ▶ Compile & Run compiles it to a real RV32 image and runs it on an emulated RV32IM machine entirely in this page — no server, nothing sent anywhere. It reuses the bw-board engine (the shecc→wasm compiler and the machine) loaded from jsDelivr at a pinned commit. shecc is a C subset, not a full compiler.

An .ino belongs in a folder of the same name; add a NAME blink line and you get blink.ino. Source: CrispStrobe/stc-compiler.
